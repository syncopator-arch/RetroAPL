# KAPL font

`kapl.ttf` is **KAPL**, an APL font designed by **Adrian Smith**
(copyright notice in the font: "Adrian Smith 1995/2001", version 1.2).

This copy is byte-for-byte identical to the `KAPL.TTF` distributed with
the A+ programming language, released by Morgan Stanley under the
GNU General Public License v2:

- A+ source, including the font: <https://github.com/tavmem/aplus>
  (`src/fonts/TrueType/KAPL.TTF`)

Adrian Smith has also placed his APL fonts in the public domain:
"All fonts listed on this page are original artwork by Adrian Smith,
and are freely placed into the public domain"
(<https://apl385.com/fonts/>). KAPL isn't among the fonts listed on
that page, so this statement is noted here as the author's general
intent; the font is redistributed under the terms it came with in A+.

The font is a separate file that RetroAPL loads at run time; it is not
compiled into the program.
